==================================================
1. MỤC TIÊU
==================================================

Triển khai một production-quality vertical slice cho mini-game:

Boss Battle

thuộc APP Tiếng Trung.

Mục tiêu không phải là làm một màn hình quiz có background đẹp.

Game phải chứng minh được một pipeline hoàn chỉnh:

SQLite / learning database
→ Existing Database Layer
→ Repository
→ Question Generator
→ BossBattleController (GetX)
→ Boss Battle UI / Renderer
→ Game Result
→ Learning Review Event
→ FSRS/Scheduler Boundary
→ Reward/Economy Boundary

Game phải đủ tốt để sau này các game khác có thể reuse kiến trúc chung.

==================================================
11. QUESTION GENERATOR
==================================================

Không dùng shuffle() + first như toàn bộ learning algorithm.

Question selection ưu tiên:
1. FSRS due item nếu hệ thống thật có FSRS/SRS state;
2. weak item;
3. item phù hợp level/unit/skill;
4. item chưa xuất hiện gần đây;
5. distractor hợp lý;
6. sau đó mới random trong candidate pool.

Nếu chưa có FSRS thật:
- không fake FSRS;
- không tự gắn nhãn một thuật toán đơn giản là FSRS;
- tạo learning/review boundary để tích hợp scheduler sau.
